# Navoda Print Out and Photocopy — POS Web App (Mobile Ready)

## Run locally
```bash
npm install
npm run dev
```
Open the shown local URL on your phone (same Wi‑Fi) to use it on mobile.

## Build for GitHub Pages
```bash
npm run build
```
Upload the contents of `dist/` to GitHub Pages (recommended: set Pages source to the root of the branch you upload to).
